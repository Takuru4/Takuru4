📖 Грамматика урока

1. Сравнение: A 比 B + прилагательное

Конструкция для сравнения двух предметов или людей.

A 比 B + 形容词
北京比上海冷。Пекин холоднее Шанхая.
上海比过去更漂亮。Шанхай красивее, чем раньше.

2. Усиление: 最 / 更

最 — превосходная степень (самый). 更 — сравнительная (ещё более).

最 + 形容词 = самый
更 + 形容词 = ещё более
这是中国最大的城市。Это самый большой город Китая.
上海比过去更漂亮了。Шанхай стал ещё красивее.

3. Разница в степени

Можно указать насколько одно отличается от другого.

A 比 B + 形容词 + 一点儿 / 得多 / 数量
今天比昨天冷一点儿。Сегодня немного холоднее, чем вчера.
气温高五度。Температура выше на 5 градусов.

4. 可是 — противопоставление

Союз «но» для противопоставления двух фактов.

..., 可是 ...
上海气温高，可是屋子里没有暖气。В Шанхае тепло, но в домах нет отопления.
✏️ Мини-тесты на грамматику
1. Выбери правильную конструкцию: «Пекин холоднее Шанхая»
北京比上海冷。✅ Правильно!
北京最上海冷。❌ Неверно. Нужно: 北京比上海冷。
北京更上海冷。❌ Неверно. Нужно: 北京比上海冷。
2. Выбери правильный вариант: «Шанхай стал ещё красивее»
上海最漂亮了。❌ Неверно. Нужно: 上海比过去更漂亮了。
上海比过去更漂亮了。✅ Правильно!
上海比过去最漂亮了。<
3. Выбери правильный перевод: «Это самый большой город Китая»
这是中国更大的城市。❌ Неверно. Нужно: 这是中国最大的城市。
这是中国最大的城市。✅ Правильно!
这是中国比大的城市。❌ Неверно. Нужно: 这是中国最大的城市。
4. Выбери правильный вариант: «Сегодня немного холоднее, чем вчера»
今天比昨天冷一点儿。✅ Правильно!
今天最昨天冷。❌ Неверно. Нужно: 今天比昨天冷一点儿。
今天比昨天最冷。❌ Неверно. Нужно: 今天比昨天冷一点儿。
5. Выбери правильный вариант: «В Шанхае тепло, но в домах нет отопления»
上海气温高，可是屋子里没有暖气。✅ Правильно!
上海气温高，可是屋子里有暖气。❌ Неверно. Нужно: 上海气温高，可是屋子里没有暖气。
上海气温高，所以屋子里没有暖气。❌ Неверно. Нужно: 上海气温高，可是屋子里没有暖气。
